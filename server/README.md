# ProPhoto SMM — Backend

Обробка заявок для лендингу: **база даних (SQLite) + онлайн-оплата (LiqPay) + сповіщення в Telegram + адмінка**.

## Що вміє

- Приймає заявки з усіх форм сайту та зберігає в базу
- Одразу шле сповіщення в Telegram-групу команди
- Створює оплату LiqPay для пакетів; після оплати статус у базі оновлюється **автоматично** (через callback), і в Telegram приходить друге повідомлення «✅ Оплачено»
- Веб-адмінка `/admin`: перегляд заявок, пошук, фільтр за статусом, ручна зміна статусу

## Статуси заявки
`new` (нова) → `contacted` (зв'язались) → `paid` (оплачено) / `cancelled` (скасовано)

---

## 1. Локальний запуск

```bash
cd server
npm install
cp .env.example .env      # заповни ключі (див. нижче)
npm start
```

- Сайт відправляє заявки на цей сервер
- Адмінка: http://localhost:3000/admin (пароль з `.env`, поле `ADMIN_PASSWORD`)

## 2. Як отримати ключі

### 🔑 LiqPay (оплата)
1. Зайди на https://www.liqpay.ua і увійди через ПриватБанк / Приват24
2. Створи компанію (магазин) у кабінеті
3. Відкрий розділ **API / Ключі** — там будуть **Public key** і **Private key**
4. Встав їх у `.env`:
   ```
   LIQPAY_PUBLIC_KEY=твій_public_key
   LIQPAY_PRIVATE_KEY=твій_private_key
   ```
> Для тесту LiqPay має **sandbox-режим** — платежі не списують гроші. Увімкни його в кабінеті, поки перевіряєш.

### 🤖 Telegram-бот
1. У Telegram знайди **@BotFather** → команда `/newbot` → задай ім'я → отримаєш **BOT TOKEN**
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC-...
   ```
2. **Chat ID групи**, куди слати заявки:
   - Створи групу команди, додай туди свого бота
   - Напиши будь-яке повідомлення в групу
   - Відкрий у браузері: `https://api.telegram.org/bot<ТВІЙ_ТОКЕН>/getUpdates`
   - Знайди `"chat":{"id":-1001234567890,...}` — це і є Chat ID (для груп він **з мінусом**)
   ```
   TELEGRAM_CHAT_ID=-1001234567890
   ```

### 🔒 Пароль адмінки
```
ADMIN_PASSWORD=придумай_надійний_пароль
```

### 📢 Посилання на закритий Telegram-канал курсу
Після оплати клієнт бачить сторінку «Дякуємо» з кнопкою в цей канал.
1. Створи закритий канал або групу курсу
2. У ньому: **Керування → Тип каналу / Запрошення → Створити посилання-запрошення**
3. Скопіюй посилання (виду `https://t.me/+AbCdEf...`) у `.env`:
   ```
   COURSE_TG_LINK=https://t.me/+AbCdEf...
   ```

### 📊 Google Sheets (дублювання заявок у таблицю)
Кожна заявка, крім бази, потрапляє у Google Таблицю.
1. Створи нову **Google Таблицю**
2. Меню **Розширення → Apps Script**
3. Видали те, що там є, і встав увесь код із файлу `server/google-apps-script.js`
4. Вгорі натисни **Розгорнути (Deploy) → Новий розгортання (New deployment)**
5. Тип — **Веб-застосунок (Web app)**:
   - **Виконувати як (Execute as):** Я
   - **Хто має доступ (Who has access):** Усі (Anyone)
6. Натисни **Розгорнути**, дай дозволи (Google попросить підтвердити)
7. Скопіюй **URL веб-застосунку** і встав у `.env`:
   ```
   SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/AKf.../exec
   ```
> Якщо лишити `SHEETS_WEBHOOK_URL` порожнім — заявки просто не дублюватимуться в таблицю, база й Telegram працюють як завжди.

## Робочі сценарії

**Заявка «передзвонити»:**
заявка → база + Google Sheets → бот пише в групу організаторів → менеджер дзвонить →
вписує результат у поле «Коментар менеджера» в адмінці → зберігається в базі.

**Купівля пакета:**
заявка на пакет → база + Google Sheets → оплата LiqPay → після оплати:
статус у базі стає «оплачено», бот пише в групу ✅, клієнт бачить сторінку «Дякуємо»
з кнопкою у закритий Telegram-канал курсу.

## 3. Деплой (безкоштовно) — Render.com

1. Заллий проєкт на GitHub (див. головний README)
2. Зайди на https://render.com → **New → Web Service** → підключи свій репозиторій
3. Налаштування:
   - **Root Directory:** `server`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. У розділі **Environment** додай усі змінні з `.env` (LIQPAY_*, TELEGRAM_*, ADMIN_PASSWORD)
5. Додай ще одну змінну:
   - `PUBLIC_URL` = адреса, яку видасть Render, напр. `https://prophoto-api.onrender.com`
   - `CORS_ORIGIN` = адреса твого сайту, напр. `https://прикладдомену.com`
6. Deploy. Готово.

> ⚠️ На безкоштовному тарифі Render база SQLite може скидатись при перезапуску сервісу.
> Для постійного зберігання підключи диск (Render **Disk**) або перейди на безкоштовний **Postgres** — напиши, допоможу з міграцією.

### Підключення фронтенду до бекенду
У файлі `js/main.js` (на сайті) знайди рядок:
```js
const API_BASE = "";
```
і встав туди адресу бекенду:
```js
const API_BASE = "https://prophoto-api.onrender.com";
```

### Callback LiqPay
Нічого налаштовувати вручну не треба — сервер сам передає LiqPay свій `server_url`
(`PUBLIC_URL/api/liqpay-callback`). Головне, щоб `PUBLIC_URL` був правильний і публічно доступний.

## Ендпоінти (довідково)

| Метод | Шлях | Призначення |
|------|------|-------------|
| POST | `/api/lead` | зберегти заявку + сповістити Telegram |
| POST | `/api/pay` | створити оплату LiqPay (повертає `data`+`signature`) |
| POST | `/api/liqpay-callback` | приймає результат оплати від LiqPay |
| GET  | `/api/admin/leads` | список заявок (потрібен пароль) |
| POST | `/api/admin/leads/:id/status` | змінити статус |
| GET  | `/admin` | веб-адмінка |
